# Hunting Phone 

## Overview
**Hunting Phone Seven** is a web application that allows users to browse and search for mobile phones using an API. The application fetches phone data dynamically and displays it in an organized grid layout. Users can click on a phone card to view detailed information in a modal.

## Features
- Fetch and display phone data dynamically from an API
- Search functionality to find specific phones based on user preferences
- "More" button to load and display additional phone options
- Responsive design with Tailwind CSS
- Interactive UI using JavaScript and DOM manipulation

## Technologies Used
- **HTML5**: Structuring the webpage content
- **Tailwind CSS**: Styling and layout management
- **JavaScript**: Implementing interactivity and API calls
- **API**: Fetching phone data dynamically
- **DOM Manipulation**: Updating the UI dynamically

## How to Use
1. Visit the live website: [Hunting Phone Seven](https://hunting-phone-seven.vercel.app)
2. Browse the available phones displayed in the grid layout.
3. Use the search bar to find specific phone models based on your preferences.
4. Click on a phone card to view detailed information.
5. Click the "More" button to load and display additional phone options.

## Installation and Setup
If you want to run the project locally:
1. Clone the repository:
   ```sh
   git clone https://github.com/tasninanika/Hunting-Phone.git
   ```
2. Open the project folder and launch `index.html` in a browser.
3. Ensure you have internet access to fetch data from the API.
